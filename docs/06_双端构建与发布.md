# 双端构建与发布

## 本机工具链

Godot 4.7.2.stable.official.ed1daf0bf，Windows原生可执行和同版本官方导出模板。Windows x86_64资源嵌入EXE；Android使用预编译模板，ARM64/ARMv7共包，OpenGL Compatibility / GLES3。

Java21与Android SDK均使用本机安装。0.2.16 Android包实际manifest为minSDK24、targetSDK36、versionCode21、versionName0.2.16；以 `reports/apk_badging.log` 为准。包名 `org.railwaywarlords.game`。不运行Docker、WSL或模拟器。

`tools/build_release.py --target all`导出两端并记录 `reports/export_results.json` 的退出码、大小、SHA256。`export_presets.cfg`中不保存密码；本机签名凭据位于工作区 `.toolchain/signing`，通过Godot专用环境变量传递。密钥、密码、SDK、编辑器缓存和用户存档不进入公开工程压缩包。

Android安装包使用本地专用发布密钥签名，并以SDK原生apksigner验证。Windows测试包当前没有Authenticode发行商签名；这与其本机运行测试独立记录。

## 安装与验证

Windows解压包后直接运行 `RailwayWarlords.exe`。工程源码和媒体包含在独立工程包；安装包无需Python或编辑器。桌面UI烟测和实际完整视口截图记录在reports。

Android可把APK传到手机安装；USB连接设备后也可使用 `adb install -r RailwayWarlords.apk`。需要同一签名才能覆盖安装后续版本。当前尚无已连接物理设备的安装/触摸/性能结果，不能以签名通过代替真机验收。

0.2.9采用ruleset9和五倍地图的新坐标，旧版进行中战局使用保留的对应旧版便携包继续；养成档案独立保留。Android计划继续旧局时，请先用原安装版本完成后再更新；本次没有Android真机降级恢复的验证记录。

当前双端包目录为工作区 `output/releases/railway-warlords-0.2.16`，机器清单 `release_manifest.json` 记录实际文件、SHA、构建版本与验收状态。原图片生成记录、私有签名材料和旧归档继续留在各自工作区路径，不混入程序发布内容。已经封存的程序、录像和工程ZIP保持原字节；后续测试与文档补件单独记录，不把补件冒充重新导出的程序。Motorola X30 当前只有 2400×1080 桌面布局档案，未连接实机，不能将静态 APK 检查写成触控或持续性能通过。

## 摩托罗拉X30适配记录

按[联想/摩托罗拉官方产品规格](https://item.lenovo.com.cn/product/1019590.html)的2400×1080、20:9横屏尺寸设计。Android默认120%字号与96逻辑像素按钮最小高度，使用设备安全区域API避让开孔。画面比例采用expand，避免只在16:9固定视口中测试。

`reports/screenshots/map_x30_layout.png`及同名JSON是Windows原生Godot的2400×1080窗口/视口，实际启用移动端控件、120%字号与模拟安全边距；不是手机截屏。`legion_deployment_x30.png`及校验JSON另外覆盖编制层数、两层精锐部署和24项成就条件显示。150%字体另有实际1920×1080窗口检查。`reports/android_devices.log`记录当前无物理设备连接，因此没有X30安装、触摸、Adreno纹理兼容或持续性能实测。

Windows可执行文件经过独立运行、UI弹窗烟测和原生视口截屏。Android完成发布签名、SDK/ABI/权限检查，113份打包数据/许可、栅格来源清单和1,156项导入纹理与已测工程内容逐字节一致，其中包含历史聚落JSON；真机验收另外记录。

原生导出检查传入`--qa-session`，独立存放QA设置、养成和自动存档。构建源码指纹同时覆盖当前PNG、WAV、字体、导入配置、来源清单、schema和导出配置；APK另核对实际导入纹理，避免只比较GDScript就误认美术一致。

构建整体指纹覆盖代码、数据、当前媒体、schema与导出配置；规则/布局报告的新鲜度对应代码、数据和schema。媒体另外检查当前资源SHA、导出整体指纹、实际APK导入字节及当前原生截图，不因只修改导出配置就重复无关领域对局。

最终导出EXE的两套最大负载测试、三种AI分布与像素/算法等价见[容量性能与渲染等价](12_容量性能与渲染等价.md)。`tools/record_native_evidence.py`直接录制原生QA场景和战斗；`--only layers`生成同一暂停场景的8张原始PNG，`--only movie`直接编码原生MovieWriter视频。

0.2.9本机三种最大负载分布的最慢完整AI阶段为3319.53ms，达到5秒目标；预览P95、存档读写、最终EXE渲染及8ms结果提交检查也通过，该版性能证据的passed为true。该结论属于0.2.9原报告；0.2.11以有限范围视觉测试版交付，没有复用为当前满载性能通过。0.2.3曾测得最慢6.43秒，其未达标报告与测试版限制保留在原版记录中，不能套用为当前版的性能结论。桌面测试通过仍不代替X30真机或完整发行验收。
