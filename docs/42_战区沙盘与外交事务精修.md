## 选关地图与战场一致

旧选关沙盘只绘制陆地底色、海岸线和城市圆点。本版直接调用正式战场的 `MapView` 静态地图层，使用同一组来源数据、完整Sub2原图和原生材质：连续地表、高程光照、地形景物、海岸、湖泊、主河与支流。绘制所用的宏观底材、细节图、山地、林地和建筑仍是现有可追溯原图；不裁剪、补绘或输出拼接宣传图。

| 内容 | 实现与边界 |
| --- | --- |
| 地表 | 复用20类连续地表的来源分类和原生混合材质；选关远景保留连续底材，不再沿用战场的远景省略阈值 |
| 地形体积 | 来源高程光照与独立完整景物；地方画法表达与规则格分离，基础六边格未变 |
| 地方节点 | 原登记的首都、省城、县城、集镇和村落，按来源日期、缩放及画面间距显示；不追加虚构地点 |
| 城镇原图 | 修正建筑资源的引用类别；完整原图按实际节点绘制，目标城名称优先显示 |
| 铁路 | 仅显示当前登记日期已生效且未失效的铁路，保留原路径；圆滑转角为显示处理 |
| 地理与政区 | 使用剧本原地图及对应行政层；预览未绘制猜测战线或把城市控制点伪装成历史县界 |
| 操作 | 加减、鼠标滚轮或双指缩放；拖动平移；复位恢复战区取景，缩放上限为初始取景10倍 |
| 数据隔离 | 原地图保持只读；浏览器不建立战局、不消费战斗随机序列、不修改成长档案 |

早期剧本不能因选中状态而显示尚未到登记生效日期的地方。`active_from`含起日，`active_to`不含止日；缺少结束日期不等于已完成该地所有年代史实核验。高程、河道和植被资料各自的精度及时代边界继续参照原地图章节，未新增历史土地利用调查结论。

## 外交事务页

左栏是当前在场势力名册，右栏展示选中对象。左右独立滚动，顶部日期、行动额度与关闭按钮保持可达。单一对象仍使用完整详情宽度，多对象不再把所有卡片挤成同一行。

详情显示真实交战/中立/停战/同盟关系、借道及补给权限、最低条约期、解约日期、提案分数和逐项原因。已知编队只计入 `VisibilityRules` 对本方可见的编队；不展示全图隐藏敌军数。时限使用实际对局日期和每日回合规则计算。

宣战、停战、结盟、通知解约与援助均使用现有 `CommandKernel` 预览及 `RulesWorker` 执行，不在界面复制外交结算逻辑。禁用原因来自当前战局。援助成功后展示真实 `pending_aid` 记录，并标注收方下个行动阶段结算。接收方撤离时，既有规则退回未送达援助的一半；无战略城市据点的对象会显示相关说明。

## 每日登记一致性

61个可玩剧本原已按每日回合推进。本轮将 `content/definitions/scenarios.json` 中三条旧征服定义的 `days_per_round` 从7同步为1，并同步当前选定方向的设计表。追加三条定义表检查以及四条地方节点日期边界检查。每个阵营的单独行动阶段不额外推进日期；全阵营完成一轮后公历增加1天。

33人均有四个生前阶段，共135张独立肖像。李德胜1917年使用青年、1947年使用中年图。1947年及更晚图像仍属素材准备，当前可玩年代锚点止于1940。当前内容哈希改变，旧战局需要重开；人物、年龄精度及资料争议见[40](40_每日历法与四阶段人物肖像.md)。

## 当前核验与交付

29组/5,787项回归通过，包含88项每日历法与611项人物专项。最终EXE人物页1,725项/174张、成长事务157项/24张、地表216项与管理UI373项/99张、海岸84项/20张、图符220项/32张，共349张完整原生画面；另有18项配乐播放检查。三种布局分别为1920×1080、2400×1080/120%移动界面和1280×720/150%大字，均为Windows原生程序。

选关检查实际材质与完整景物的绘制数量、原地图只读、缩放超过2倍、拖动不误选和复位。外交检查名册目标与按钮一致、已知编队遵守可见性、真实扣款50、在途对象及冷却禁用；保留收方撤离半额退回的既有规则。报告绑定当前源码及导出EXE，未用源工程试跑代替最终程序。

人工完整查看其中16张，范围与问题见[有限原生查看记录](../reports/atlas_office_native_review.json)。APK0.2.24/code29沿用签名，v2/v3、两种ARM架构、125份JSON/许可、1,304张导入纹理及3首OGG均核对实际载荷。完整CRC、Git字节及程序身份由交付门槛另行核对。
