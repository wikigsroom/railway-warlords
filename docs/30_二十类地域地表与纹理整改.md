# 二十类地域地表与纹理整改 · 0.2.13

0.2.17 的连续地表网格、全亚洲底材与单层控制色修订见 [34 连续地表混合与控制色去重](34_连续地表混合与控制色去重.md)；本章的原始实施版本与历史测量保持其语境。
本章记录 0.2.13 的 20 类与 80 张细节原图基础，当前0.2.19保留这套分类。0.2.14 另加 20 张连续底材，并下调细节叠加强度；地表生产参数见 [31 连续地表与水系层次](31_连续地表与水系层次.md)，0.2.18的缩放层次与去除重复线符见[35](35_地图缩放层次与精确点选.md)。

[中文 README](../README.md) · [English README](../README.en.md) · [文档索引](00_程序文档索引.md)

本轮解决底纹同质化：增加 **20 类地域地表、每类 4 张独立 Sub2 原图，共 80 张**，并调整实际地图中的材质显示与空间选图。当前运行 PNG 共 **1,136 张**，地图资源合计 **950 张**。原有 796 张扩充原图及 74 张基线继续保留；新图不以改色、镜像或裁切副本充数。

这些是可在真实地图中观察、点选、查看名称的地表表现类型。通行、掩护和水陆判定继续由实际格子的 12 类规则地形决定，详情面板同时显示二者。生态区地表不会凭空增加河流、森林、湿地障碍或历史地块边界。

## 问题与落实

| 原问题 | 本版处理 | 可复核位置 |
| --- | --- | --- |
| 草土、沙地、林下土缩小后都变成接近的淡色噪点 | 提示词分别约束草叶团簇、风积砂纹、角砾、针叶、阔叶、盐斑、潮湿土团与碎岩；兼顾中尺度结构和细颗粒 | 80 份原始提示词与 PNG |
| 柔边区域过宽，材质被基础底色冲淡 | 完整材质网格的实心比例从 0.50 调至 0.70；新底纹战术透明度 0.94、战略透明度 0.91 | `presentation/map_details.gd`、`map_terrain_surfaces.gd` |
| 同一底图连续落在相邻蜂窝格 | 六邻格拓扑选图，四张原图稳定分配；同类相邻格不会使用同一张源图 | `tests/terrain_surfaces_test.gd` 与实际视口报告 |
| 随机换图无法反映地域 | 使用归档生态区原多边形、地图高程和已有河谷来源筛选；无随机地域分类 | `terrain_surface_regions.json` 与独立地理审计 |
| 素材文件存在，但玩家无法查看或辨认 | 地格检查器显示当前地表名称；说明书入口提供三页“地形图鉴”，可逐张切换四个真实素材版本 | 当前 EXE 的图鉴和地图原生截图 |

势力覆盖仍是独立半透明层：基础控制色场约 0.20—0.23，局部城市影响区覆盖为 0.26。新底纹的透明度与势力覆盖分别设置。材质变化、占领变化和玩法随机流彼此独立，平移缩放不会使地表跳图。

## 真正接入地图的范围

地理编译给 6 张地图登记了 **126,510 个地域材质候选格**。实际落图还检查水体、道路、城市、浅滩、完整材质脚印和海岸安全边界，因此候选格数不能当作最终贴图实例数。

| 地图 | 有地域来源的候选格 |
| --- | ---: |
| 亚洲战略层 | 3,391 |
| 中国东部征服层 | 53,855 |
| 汉口 | 355 |
| 京奉 | 45,368 |
| 京津 | 23,135 |
| 南京—浦口 | 406 |

亚洲战略层实际有全部 20 类，不把各地不可能出现的所有类型强塞进每张局部地图。沙地、盐生草甸、高寒地表、河谷冲积土都有独立的来源条件。道路、城市、港口、河流、海域和浅滩优先使用其真实功能表现。

原始地图 JSON、可通行规则、城市、铁路、历史行政区和起局归属不因新增材质被改写。材质 ID 保存在表现层副本中，不进入战局规则随机数和胜负计算。

## 玩家如何查看

1. 主菜单进入游戏说明，选择“地形图鉴·20类区域地表”。
2. 三个标签分别展示草地与荒漠、寒带与林带、河谷与峰岭。
3. 每张卡片的切换按钮显示四张独立原图，原图完整显示。
4. 在正常战局点选空地，右侧详情显示实际规则地形、地域地表名称、海拔及步骑机动费用。

图鉴是实际 Godot 控件与 TextureRect，可交互。交付的地图图、图鉴图均由实际程序原生截图，不是拼接概念图。

## 来源、精度与历史边界

使用 [RESOLVE Ecoregions 2017](https://ecoregions.world/) 的归档矢量多边形，署名 Dinerstein et al. (2017)，[论文 DOI](https://doi.org/10.1093/biosci/bix014)，CC-BY 4.0。生态区定义及数据说明亦可见 [Google Earth Engine 原始目录](https://developers.google.cn/earth-engine/datasets/catalog/RESOLVE_ECOREGIONS_2017?hl=en)。高程及河流沿用本工程已归档 DEM、HydroRIVERS 和历史地理资料，精度见 [29](29_地表材质与细水系.md)。

现代潜在生态区用于**代表性地表选材**，不等于 1840—1940 年逐年的实际森林覆盖、耕地、土壤分类、岩性或盐沼水域测绘。林带底材不自动添加树冠或森林掩护；河谷底材不生成新的河道或渡点。河谷距离阈值为地图世界单位，随地图尺度变化，不是统一的米级土壤调查。

未下载或接入 OpenLandMap 土壤栅格，也没有声称已完成逐格历史土地利用复原。

- [地理编译记录](../reports/terrain_surface_geography.json)：20 类均有实际地图候选，原始规则地图哈希不变。
- [独立素材/地理审计](../reports/terrain_surface_asset_audit.json)：直接读取原始来源多边形、80 张源图、提示词、导入配置与源/引擎哈希。
- [152 项专项回归](../reports/terrain_surfaces_tests.json)：类型、完整素材引用、六邻格排重、稳定性、地理门控、透明覆盖及规则地图不可变。
- [当前 EXE 的原生图鉴、地图和 UI 证据](../reports/terrain_surface_native_evidence.json)：绑定当前运行源码与实际 EXE 的 SHA-256；桌面及 X30 比例布局分别记录。

在同样缩至 128 像素的亮度统计中，旧材质亮度标准差中位数为 4.89，新材质为 14.34。这个指标只说明小尺寸纹理更易保留，不是审美评分，也不是与《欧陆战争6》画面等同的证据。

正式美术发行批准、全区域季节与过渡套件、全兵种动作、全部关卡人工平衡及 Motorola X30 物理验收仍未完成。新素材数量、程序回归通过与商业美术完成度分别记录。

## 工程入口

- `tools/generate_terrain_surfaces.py`：不可变计划、80 次独立生成和安装。
- `tools/compile_terrain_surfaces.py`：生态区、高程和河谷门控，输出表现层地域表。
- `tools/audit_terrain_surfaces.py`：独立核对来源、地理选择、原图和导入。
- `presentation/map_terrain_surfaces.gd`：地域类型、名称、四图稳定选取和材质强度。
- `presentation/map_details.gd`：完整材质柔边网格、海岸脚印检查与地景排重。
- `presentation/war_room_screens.gd`：可交互地形图鉴。
- `tools/capture_terrain_update.py`：只运行当前已核验 Windows EXE，记录真实操作和原生截图。

重建生成和地理编译依赖原工作区的指定 Sub2 技能及归档地理源文件；克隆仓库后直接运行游戏不需要网关或原始 GIS 工具。提示词、图像哈希、来源和编译结果均随源码保存。
