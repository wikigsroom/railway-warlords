# 0.2.31 低地底纹与河岸材质调整

本轮针对大片灰褐色低地难以区分草地与露土、纹理笔触缩得过细，以及河面中央过亮、河岸形成连续亮条的问题。它是地图材质专项修订，整体美术尚未达到《欧陆战争6》的目标品质。

## 原图与地表

通过指定的 **sub2-image-gen / gpt-image-2.5 / high** 生成两张独立原图，分别替换现有温带草地和亚热带腐殖质底材。请求尺寸为1024×1024，服务实际返回1254×1254；运行副本保持原始生成字节，Godot正常导入时使用384像素上限及mipmap。没有手工拼接、裁切、补绘或生成派生贴图。

| 地表 | 本轮变化 | 适用范围 |
| --- | --- | --- |
| 温带草地 | 更明确的橄榄绿低草笔触与少量露土 | 已经分配该材料的地块 |
| 亚热带腐殖质 | 暖绿低矮地被与可见有机土壤交织 | 已经分配该材料的地块 |

这两种材料的整图显示周期调整为384世界单位，其余18种维持224。所有材料仍固定在世界坐标中；连续地表混合、缩放mipmap与独立细节原图继续使用。地表种类仍是20类，细节图仍是80张，不能将两张替换原图算成两种新增地形。

本轮增加2张存储原图，全部注册PNG为2,509张。地图资源存储1,015张，其中42张旧底材保留为历史来源，当前可用地图资源仍为973张。来源、提示词和SHA-256见[素材索引](asset-provenance/index.json)、[源图查看记录](../reports/ground_material_v0231/source_review.json)及[安装记录](../reports/ground_material_v0231/installation.json)。原生产计划和旧图片均保留。

这些是地图的代表性表面材料，**不是某年历史植被调查**。没有因此给城市、河滩或生态区添加树林、庄稼、农田、水体或通行属性。现有生态区域、河道、海岸、城市坐标、历史部署与48世界单位操作蜂窝不因本轮选材而变化。原有历史资料的已知问题仍见[完成度评估](23_当前完成度评估.md)。

## 河岸与控制色

河岸外缘改为逐渐变淡的半透明材料，降低原来的均匀亮条。水面改为较暗中央与安静的浅缘，减轻狭窄河带像凸起管道的观感。这些是绘制颜色和透明度的变化，现有水系中心线、汇流点、宽度规则、断面顶点及桥渡保持原数据。

控制区继续使用已有的单层半透明覆盖。新底纹在覆盖下保留草地和露土差异；同一机位分别检查开启和关闭控制色的画面。城市影响范围仍是玩法表达，不能视作经过核验的历史行政边界。

## 已完成的开发验证

两张完整源图均实际查看。武汉、北京和山海关共18张候选整幅视口用于比较新旧材料与224/384显示周期；随后又完整查看6张正常384像素导入后的开发引擎画面。候选、正常导入和正式导出程序的证据分别记录。

五组现有组件检查通过，共273项：核心规则102、地表连续性39、源陆地覆盖45、地域选材39、水系几何48。正常导入专项的24项检查通过，验证20层384像素材质、显示周期、控制色切换及战局/随机流保持。原生GPU开发检查48项通过，分别验证整图直接取样、真实生产混合、蜂窝接缝、绘制顺序和移动相位。独立20张底材审计及2,509张资源字节/格式检查通过。

正常导入试验保留当时的源码身份；其后仅整理素材清单顺序，并修正CLI专用GPU校验的参考取样周期。正式双端构建与正式EXE复验会绑定最终源码身份，不能用前一阶段身份代替。

## 仍未完成

武汉外框留白、部分大面积冲积土、粗折线河道与山脚衔接仍然明显；真实支流和年代岸线需要来源资料支持。全兵种连续动作、起局历史问题、Motorola X30物理设备安装与性能测试仍未完成。上述数量和通过检查不代表商业画质、史实完整性或《欧陆战争6》品质达标。

后续配乐继续使用用户指定的 **music-gen-remote-YuE2**，以无台词、无歌词的纯器乐为主。本轮没有生成或替换音乐；已有本地曲目的真实来源保持。
