# 养成、军团与地图事务修订

本章功能在0.1.1（schema2 / ruleset4）落地，0.2.0（ruleset7）继续使用并重新执行243项养成与13项事务检查。本次历史事件与结算改动见[09 历史事件与征服结算](09_历史事件与征服结算.md)，历史和美术发行审核状态独立记录。

## 军团编组

军团页面可选择基础兵种的1–3层编制及三种精锐的1–2层编制，具体层数依兵种表；价格沿用基础成本及精锐×1.5倍率，逐项向上取整后按层数计算。军团的部署现金预算和局内军需分别记录，不消费生涯功勋。

界面和开局都调用`LegionRules`校验预算、兵种许可、精锐共享名额、兵种数量上限、将领名额、重复将领，以及修桥/护航/跨江所需的角色。无合法位置时拒绝整套开局，避免丢掉玩家已选编队。装甲列车只部署到可用轨道；修桥工兵重新定位时保留其层数。

1–4题没有精锐名额，5–12题有1个。为保持固定挑战，允许精锐的题目向双方提供相同的科技快照：三种精锐的对应科技为2级，前置科技按登记条件开放；不带入生涯科技、军衔、勋章和自选主动。双方的精锐、将领和成长规则可复核，军团难度固定为普通规则。

敌军配置由题目决定，不再随着玩家减少编队而缩小敌军数量。此项使同题成绩可比较，但不等于12题已完成策略平衡验收。

征服选择页与领域开局也共用起局条件。三个年代各7套完整可选起局，均有战略据点和起始部队，并检查不会在未执行动作时立即败北；未提供完整起局的势力不能绕过菜单强行开始。不添加虚构城市、驻军或归属来填补缺项。

移动端编组加减按钮至少96×96逻辑像素，层数和将领选择也使用96像素最小高度。导出界面检查验证这些尺寸，实际手机触摸验收继续单列。

## 奖励与成就

首胜、追加星级、征服三星、成就奖励各自记入一次性账本。战役从一星提高到三星，只补两颗尚未领取的星级奖励；以后重打或读回同一份完成存档，不再发放这份奖励。征服首胜后再提高到三星，可领取尚未得到的三星里程碑。旧档案已经记为三星的记录不会重复补发。

战役章结业和六场三星按不同任务统计，不把同一关的三个难度当作三场不同战役。弱势挑战标签显式登记于各年代剧本，只用于游戏成就，不能解释为对历史实际军力的考证结论。成就页显示条件与累计进度。

战术和后勤条件来自成功规则命令。断路本身不加成就：先记录断路前后供给覆盖消失的敌军，待其供给实际下降才计数；修好线路、恢复连接或不再敌对会清除等待记录。此记录随存档保存。压制/舰炮支援后占城要求在同一回合完成，标记在占领后清除；城防修复会清除旧破防标记。

击破统计使用攻击方/反击方归属。敌军在进入自身阶段时因断粮死亡，不计成玩家击破；玩家在敌军阶段反击取得的击破仍计入玩家。异步完成的工事和抢修使用实际所属，避免算给刚结束阶段的另一方。

未结束、内容版本不符、debug或投降战报不能发放本版生涯奖励。标准化战绩按同题、同难度、同阵营、同内容指纹与同规则版本分组；缺少版本信息的旧成绩保留在生涯，不混入当前榜单。新局使用独立随机ID，避免快速开局共用奖励账本键。

## 地图事务与性能

自然地理、行政图形、基础格数据递归只读，在连续命令之间共享。部队、城市、资源、队列、事件、铁路损坏与运力仍独立复制。青岛接收时仅复制需要改变的格和格表，提交后重新只读；上一份状态、原始地图及源资料保持不变。加载存档后恢复同样的只读状态，序列化内容与校验和不变。

`transaction_tests.json`包含13项检查及30次真实征服状态复制测量。0.1.3的Windows原生Godot样本中，全量复制中位30.521ms，事务复制1.764ms；P95分别39.543ms和2.570ms。采样时另有本机任务运行，数值只代表该批桌面样本。此项只测状态复制，不证明整个AI阶段、渲染或Android真机性能。

## 验证范围

`progression_tests.json`记录243项检查。24项成就条件均覆盖；战术和后勤用实际提交的命令，奖励和章结业用明确的结束战报输入测试账本层。它不证明18个历史关卡均被人工通关，也不证明历史军事部署正确。

导出的Windows程序另外执行编制选择、加入两层精锐、确认部署与成就条件显示，分别保存1920×1080和2400×1080原生画面及校验记录。后者是X30尺寸的桌面布局检查，不是手机GPU或触摸实测。

## 存档兼容与发行边界

养成档案可沿用。0.1.0–0.1.3的进行中战局属于旧规则指纹，0.2.0会明确拒绝加载；原存档和对应旧交付包保留，Windows可用对应旧便携版继续该局。Android计划继续旧局时，先完成旧局再更新；没有真机降级恢复的验证记录。新版需要另开战局。

完整军事起局、装备和县界考证，全部166项素材发行审核，33题策略/难度/节奏，以及摩托罗拉X30物理设备验收继续按原13章执行。这里的自动回归不能替代这些门槛。


0.2.0事务复制的当前实测见`reports/transaction_tests.json`，上文0.1.3数值保留为历史样本。局内单位经验、存档骰流和自动作战演出同步见[系列对标与实机修复](11_系列对标与实机修复.md)，不改写局前科技/奖励登记表。
