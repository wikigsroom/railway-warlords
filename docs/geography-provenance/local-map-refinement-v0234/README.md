# 局部地图来源留存 / Local-map provenance

本目录保留0.2.34迁移前的两张局部图基线、原始高程响应ZIP、河段来源及负值复核。JSON与ZIP按原字节复制；ZIP包含922份提供方响应、92,120点样本及请求坐标。

These are verbatim source records: the pre-refinement local-map baseline, original elevation response ZIP, channel identifiers and negative-value review. The ZIP retains 922 original provider responses and 92,120 sampled values.

现代DEM、现代河段和近似城市参考点不能视为1924年城市、河岸或码头的测绘。详细限制见[52章](../../52_局部战区五倍比例与独立江岸.md)。

Modern elevation and river data and approximate city reference points are not a historical city, bank or wharf survey. See chapter 52 for limits.

`coastal_control_before.zip`另行保留控制色漏边修复前的三张沿海网格、当时的目录SHA与失败核验报告；其中的陆地、岸线、行政边界可与当前网格逐项对照，控制三角形按当前真实陆地重新生成。

The separate coastal-control ZIP preserves the three previous meshes, their catalogue identities and the failed independent validation. Non-control geometry can be compared directly with current meshes; control triangles are rebuilt on the reviewed land.
