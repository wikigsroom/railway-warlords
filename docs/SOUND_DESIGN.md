# 铁道烽烟声音设计

1920年代军事沙盘使用干燥短促的金属、木材、蒸汽和低频火药声。音效只提示已经发生或已知的战场状态，不泄露战争迷雾中的敌军。八路音效复用播放器；音乐独立控制；暂停和退出停止不需要的播放。

| 事件 | 声音与目的 |
|---|---|
| 选中 | 80ms木质机关点击，低音量确认 |
| 行军 | 280ms脚步、皮革、地面短瞬态 |
| 步枪 | 180ms干燥爆音加低频枪体 |
| 机枪 | 450ms三个节奏爆发，区分压制 |
| 火炮 | 700ms低频冲击与快速噪声尾音 |
| 击毁 | 800ms低频碎裂与衰减，提示损失 |
| 占领 | 500ms上行谐波确认，提示进度 |
| 铁路运输 | 800ms轮轨节拍与蒸汽短音 |
| 修复完成 | 450ms金属敲击，提示恢复 |
| 战法 | 600ms上行号令，不与枪声混淆 |
| 断粮、失败 | 700ms低音双脉冲，提示危险 |
| 胜利 | 1.6秒四音短号角，明确完成 |

三条16秒原创循环分别用于战役菜单、战斗和胜利。简洁五声音型、低音持续音与木质节拍，避免音乐掩盖命令反馈。全部由Godot原生PCM合成并保存WAV，固定种子，单声道22050Hz、16bit，峰值保留余量；不用商业录音，不调用外部音频生成服务。

0.2.0新增木骰和螺旋桨声，14音效+3音乐，完整方案见[工程声音设计](../SOUND_DESIGN.md)。音效在实际开火/命中时播放，退出停止播放器并释放流。
