# 铁道烽烟声音设计 · 0.2.21

当前 BGM 使用用户指定的本地 YuE2 路线。三首原创曲《铁道烽烟 · 山河余烬》《山河经略 · 江流与驿路》《铁路线上的交锋》各180秒，共9分钟，按无台词、无歌词的纯器乐谱面创作。菜单、推演与交锋共享旋律动机，以不同力度、配器和速度形成场景变化。[试听、规格与核验范围](39_本地YuE2纯器乐配乐与场景衔接.md)。

Godot以48 kHz混音，提前准备三条OGG压缩流；2.4秒等功率交叉淡化，24秒没有新交锋后回到战略配乐。完整解码和18项原生播放检查分别记录，主观听辨和Motorola X30物理扬声器尚未签核。

1920年代军事沙盘使用干燥短促的金属、木材、蒸汽和低频火药声。音效只提示已经发生或已知的战场状态，不泄露战争迷雾中的敌军。八路音效复用播放器；音乐独立控制；暂停和退出停止不需要的播放。

| 事件 | 声音与目的 |
|---|---|
| 选中 | 80ms木质机关点击，低音量确认 |
| 行军 | 280ms脚步、皮革、地面短瞬态 |
| 步枪 | 180ms干燥爆音加低频枪体 |
| 机枪 | 450ms三个节奏爆发，区分压制 |
| 火炮 | 700ms低频冲击与快速噪声尾音 |
| 击毁 | 800ms低频碎裂与衰减，提示损失 |
| 占领 | 500ms上行谐波确认，提示进度 |
| 铁路运输 | 800ms轮轨节拍与蒸汽短音 |
| 修复完成 | 450ms金属敲击，提示恢复 |
| 战法 | 600ms上行号令，不与枪声混淆 |
| 断粮、失败 | 700ms低音双脉冲，提示危险 |
| 胜利 | 1.6秒四音短号角，明确完成 |

此前三条16秒Godot合成循环保留为兼容回退资源；正常游戏使用上述YuE2配乐。既有14个音效继续使用固定种子的Godot PCM，22050Hz、16bit单声道，峰值保留余量，不使用商业录音。

0.2.0新增木骰和螺旋桨声，14音效+3音乐，完整方案见[工程声音设计](../SOUND_DESIGN.md)。音效在实际开火/命中时播放，退出停止播放器并释放流。
