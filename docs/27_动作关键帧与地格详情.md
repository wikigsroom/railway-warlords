# 动作关键帧、地格详情与 HUD · 0.2.11

本章保留 0.2.11 的动作与 HUD 修订记录；其中素材总数、截图及验收范围属于该版。当前地图素材、地表与细水系以及本版测试状态分别见 [28](28_地图素材扩充与去重.md)、[29](29_地表材质与细水系.md)和[测试与验收](05_测试与验收.md)。

此版围绕实际游玩中的三个问题继续修复：地块类型和作用不清、单位缺少真实方向与动作姿态、战斗演出被界面遮挡。地表连续底材、树丛/山脊体积及有来源水系沿用 [0.2.10 实现](22_地图细节边界与单位动效改版.md)；没有更改真实地理坐标、基础蜂窝、兵种规则或战斗随机流。

## 逐格内容与立体表现

地图上的平原、林地、丘陵、山地、高山、湿地、河流和海面继续分层显示。树冠、树干、明暗面与落地阴影提供树丛体积；山脊采用较小对象和柔边地面阴影，势力仍为可透出地物的区域色层。没有用随机小溪、树木或田垄填满资料不足的区域。

点击没有单位/城市/聚落的地块，右侧显示该格的真实地形名称、地形原图、自然地貌、来源支持的林地/湿地说明，以及步兵、骑兵、车辆、水路移动成本和掩护值。仅当数据存在时显示 `elevation_m` 或 `relief_sample_m`；亚洲战略地貌类别不被包装成实测海拔。地形详情仅读取已有数据，不改变行军成本或战局。

## 四向动作原图

普通步兵已有北、东、南、西四张待命图，本轮增加每向行军 A、行军 B、射击、受击四张，共 16 张独立图片。全部使用指定 `sub2-image-gen / gpt-image-2.5 high` 路线直接生成，实际源图尺寸均为 1254×1254；请求尺寸与实际尺寸分开记录。没有通过翻转、裁取或拼接制造方向或动作。

源图与提示词保留在 `output/imagegen/warlord/ew6_v025/actions/`。北向行军 B 的首稿步态不清，另行完整生成 r002；r001 及其提示词仍保留在修订历史。`assets/manifest.json` 登记当前字节、来源与历史，`presentation/data/unit_actions.json` 登记四张待命图及十六张动作图。

Godot 使用整张纹理。透明区域的测量结果仅用于完整纹理的显示比例和足底锚点，不写回、裁切或重绘 PNG。地图按路径切换 A/B 姿态；攻击时切换射击姿态，命中时目标切换受击姿态。地图单位保留实际世界方向，交战窗的左、右单位分别使用东、西方向的真实源图。

其他兵种继续使用各自四向图与运动、弹道、后坐、受击反馈，本轮新增独立动作关键帧只覆盖普通步兵。两张行军姿态不等于完整流畅动作周期；装填、阵亡、连续八向和其他兵种动作仍未齐备。部分生成图的装备和编队细节仍需统一。

## 朝向持久化

新增 `FacingMemory` 保存每个现存单位的世界朝向。移动按最后一段路径确定方向；射击者朝向目标，受击者朝向来袭方；停步后保持。舰船不再在选择四向纹理后额外旋转整张图。

朝向属于表现数据，随手动/自动存档保存在规则状态之外并校验字节，不污染战斗数值或随机流。加载旧存档时可从保留日志恢复已有信息；旧版本已经丢弃的事件无法凭空重建。有完整朝向记录的新存档不依赖最近 250 条事件日志。损坏存档回退与跨战局隔离继续验证。

## 界面与交战窗

顶栏采用实际最小高度；单行文字截断时保留完整提示，防止长资源文本强行换行挤压地图。任务牌、图层工具和检查器支持滚动。地形/势力图例使用扣除界面后的地图区域，避免被底栏和检查器遮住。图例开关会同步到前景层。

交战窗绘制在界面上层，根据可用区域等比缩放，准备、开火、骰子、命中和结算不再落入底部命令栏。该修改同时验证大字和窄窗口；桌面 2400×1080 移动布局并不代表 X30 物理设备验收。
