# 欧陆战争6对标与美术改版 · 0.2.9

本轮继续将《欧陆战争6：1914》作为主要视觉对照。《铁道烽烟：军阀时代》使用自己的历史剧本、地图资料、素材和规则；新增素材只经用户指定的 Sub2 路线生成。当前源码版本为 0.2.9；亚洲战略层新增的城市、海岸、河流和势力色块使用运行时几何与数据，不把第三方游戏画面或素材放入运行时。顶部资源栏、任务牌、图层控制、侧边检查器与底部命令卡的 UI 结构已经统一到同一套钢灰/黄铜/纸张规范，细节见 `docs/26_欧陆战争6_UI结构与视觉对标.md`。

## 对照依据与观察范围

查看了 [EasyTech 官方游戏手册](https://ew6w.ieasytech.com/manual/en/?fwg=website) 的模式、征服说明、城市操作和目标区域六张原始图片，并阅读其单位、将领、设施、交易、外交与科技说明；[官方商店页](https://play.google.com/store/apps/details?id=com.easytech.android.ew6w)用于核对产品功能。研究记录和原始 URL 保留在工作区 output/research/european_war_6/sources.json。官方图片仅用于研究，没有放入游戏纹理或重新拼接。

官方实机图片体现出自然绿色陆地、蓝绿色水面、立体山峰与城镇、多个小人组成的军阵、醒目的国界以及简洁金属面板。当前改版将这些可观察的特征落实到自己的地图、兵种和 HUD。官网预告片页面用于确认官方来源，未把未实际观看的逐帧动作作为测试结果。

## 动效与结果的关系

演出由 BattlePlayback 的真实命令事件驱动。普通移动约 0.28–0.64 秒，主攻击小窗约 1.55 秒，反击约 0.78 秒，航空约 1.1 秒；可调整速度、跳过和减少动态。瞄准、骰定、开火、命中四个阶段与真实事件播放进度同步，开火和受击分别在事件阶段触发音效。机枪有短连续弹道，炮兵用弧线与爆炸，受击有短震动、HP 和城防变化，阵亡淡出、占领换旗。移动单位追加按定义表运动档案的姿态和 trail，静态单位仍由Sub2原图绘制。

骰子滚动中的过渡面只用于表现；停下来的骰面、倍率与伤害都读取已经结算的 CombatRandom/命令事件。动画不再次掷骰，不生成伤害，不改变 AP、弹药、随机流或最终战局；跳过也保留同一结果。原生 MP4 直接编码 Godot MovieWriter 输出，没有画面拼接、字卡补帧或设计图覆盖。

## 素材与完整设计图

本轮接入 117 项 EW6 方向原始栅格，其中53项为原有地面、山地、聚落、UI、特效和背景，32项为旧斜向军阵源图，64项为16个兵种族各自独立生成的北/东/南/西军阵源图。工程共有238项栅格，未替换的头像、图标等继续保留来源和待审核状态。每项源 PNG 与游戏副本字节一致，提示词、修订、SHA 和生成路线由 manifest 记录。

新完整概念图为一次直接生成的 [EW6 方向总版面](../../../output/imagegen/warlord/ew6_v025/full_gameplay/r002/source.png)，并保留 [提示词](../../../output/imagegen/warlord/ew6_v025/full_gameplay/r002/prompt.txt) 与 [来源记录](../../../output/imagegen/warlord/ew6_v025/full_gameplay/r002/provenance.json)。它用于整体色彩与构图参考，其生成地理投影和人物肖像未经历史准确性审核，不能作为当前游戏实机图或历史地图。初次生成含未经支持姓名的 r001 与海材质含完整场景的 r001 均保留拒收记录，没有当作运行素材使用。

Godot 场景使用独立原图、控件、原生矢量边界和程序动画；没有把设计图裁成按钮、兵种或地图拼片。

## 历史与地理约束

操作蜂窝半径仍为48像素，已放大的五倍格网、海岸、河流、铁路、SRTM高程和 ENP 年代省级轮廓不因美术重做而改变。全国最大图为74762总格/71386有效格；55个功能据点以及67个展示地方节点分别记数。额外节点包括56县城、9村落、2省城。

色块分成两层。战术图使用真实陆地和年代省级轮廓裁切的城池影响区，采用约 26% 的半透明 EW6 式区域染色；亚洲战略图没有登记可用的历史行政多边形，因此使用真实战略城市节点及其当前 `owner_id` 做确定性的六边形 Voronoi 控制场，透明度为 20–23%，只表达“当前势力覆盖到此地”的读图辅助。两层都随玩家占领更新，边界线和图例负责强调归属，底图中的海岸、河流、铁路和地貌继续透出。战略控制场是演示层，不等于考据完成的历史县界或某日真实军事前线。地方名和坐标继续使用已有资料，不能用生成图片添造岛屿、山系、村庄或机场。详情见 [历史地理](07_历史地理与地图美术.md)、[五倍格网](14_地图比例与五倍格网.md)、[历史聚落](15_历史聚落与势力地图.md)。

### 地图格的实际内容与图层顺序

每个战略格仍是 48 像素操作蜂窝，实际字段来自 `content/maps/asia_strategic.json`：`terrain_id`、`natural_terrain_id`、`render_land_covered`、坐标和地点/铁路引用。渲染顺序固定为：Natural Earth 陆海三角化底面 → 平原第二材质和六边形立体明暗边缘 → 当前势力半透明控制场 → 逐格地形图块（city/ford/forest/hill/mountain/peak/port/river/road/wetland）→ 类别 relief、等高线与山脊 → 有来源且按日期显示的林地地名节点 → 城池影响区 → 海岸、河流、桥/渡口 → 铁路、格网、地名和单位。点击“地形”可以关闭逐格图块、平原变体、明暗边缘与 relief，以检查真实地理底面和政治层是否互相污染；点击“势力”可以检查原始自然地表。

战略控制场的当前证据为 1840 清国起局：2,681 个真实陆地格被 16 个当前城市归属势力分配，1,063 个无城市影响的远端陆地格保持自然底色，产生 464 段跨势力边界。这个分配只改变绘制层，不写入 `state.map.cells`，不会改变移动、战斗、补给或存档。桥和渡口也只从地图的真实 `crossings` 端点绘制，未登记的河段不会凭空出现桥。

## 交付验证与未完成验收

territory_visual_tests.json 使用原发布征服起局的完整 Godot 视口，比较自然地图与势力开启后的同一像素，并检查蓝/红在全图和战术缩放下的可辨性及完整战局/随机流未变。五张原始 PNG、日志和检查结果随源包交付。双端版本、资产来源、导出 EXE、原生录像、回归、AI 完整对局和最大地图性能按当前源码重新验证，结果以 [测试与验收](05_测试与验收.md)及原报告为准。

这是向《欧陆战争6》方向重做并可实机查看的测试版。商业作品的最终美术和动效水准仍需要实际观感与正式验收；自动检查不能证明两款作品已经完全同等。军事起局/装备/县界、全部素材正式审核、33项人工策略平衡，以及 Motorola X30 的真实安装、触摸和持续性能仍待验收；桌面2400×1080移动布局和 APK 核验不冒充物理手机结果。


本轮已完成16组规则/输入/历史/演出等回归共3148项，原实现等价2380项/799命令，领土实际像素14项。短局318回合、完整征服425回合；两类AI测试初次使用同一默认输出路径，后者覆盖前者汇总，现已按完整原生日志逐条恢复并核对，6局完整原报告保留原字节。来源SHA和恢复方式见 reports/ai_log_reconciliation.json，未模拟新对局或改写记录的单局字段。

整幅视口比较曾发现极小远景军阵在透明缓存中出现最多57/255的局部通道差，原失败报告继续保留，未放宽阈值。当前势力控制层分成战术约26%城池影响区和战略20–23%当前归属场，确保海岸、河流、铁路和地貌透出；远景编队仍使用像素对齐的识别标记，正常战术缩放使用独立四方位军阵源图并由事件保存静止朝向。四组完整视口像素对比、双端、录像与性能检查均已按当前源码重做。

原生复核另修正地图层次：目标牌、图层按钮和小地图始终在地图军阵/特效上方；交战小窗在地图文字上方，暂停、生产等模态面板在整个战区上方。暂停原始视口05_pause_overlay.png随领土检查一起保留。
