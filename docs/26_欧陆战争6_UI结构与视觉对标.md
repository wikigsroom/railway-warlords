# 欧陆战争6 UI结构与视觉对标 · 0.2.12

当前修订说明：地格检查器使用实际选中的地表原图和简短材质名称；HUD 三视口证据见 [测试与验收](05_测试与验收.md)。下文保留 0.2.9 的 UI 架构重构说明及其旧证据出处，当前导出状态以新报告为准。

本文件只讨论界面结构和界面视觉，不把《欧陆战争6》的素材、文字或版式文件放入本项目。对照依据是官方手册中可观察到的战场顶部信息栏、城市/部队信息牌、底部行动栏、战斗结果牌与钢铁/黄铜边框；本工程继续使用自己的中国近代历史资料、自己的 Sub2 原图和自己的命名。

## 对照后的信息架构

| EW6 可观察的层级 | 《铁道烽烟》运行实现 | 交互目的 |
|---|---|---|
| 顶部资源、日期、回合和玩家势力 | `build_battle()` 创建钢灰顶部栏；`refresh_battle()` 用资源芯片、战场时钟和当前行动方刷新 | 玩家不离开地图即可判断军费、粮秣、军备、燃油、白银、回合与战争疲劳 |
| 左侧目标/任务牌 | `ui_paper_panel` 任务牌，目标、进度、天气、指挥与运力集中显示 | 目标牌与地图保持同一视线，目标进度不再散落在右侧检查器 |
| 中央地图与浮动地图图层 | 地图继续由真实海岸、河流、铁路、蜂窝、地形素材和势力控制层构成；势力/地名/铁路/补给/全图按钮收进独立 `ui_steel_panel` | 图层切换不改变规则数据，也不会遮挡战场主体 |
| 右侧选中对象检查器 | 部队和城市均显示检查器标题、当前势力色带、肖像/建筑图、生命/城防、属性和合法命令；检查器与右侧图层轨分栏，随窗口高度收缩并可滚动 | 把“选中对象是谁、属于谁、现在能做什么”固定在地图右侧，保留 EW6 式中央地图视野 |
| 底部命令卡 | `hud_button()` 使用 `ui_order_card`、命令图标、悬停/按下/禁用材质；移动、攻击、战法、整补、铁路、补给、地名、全图使用稳定图标映射 | 命令状态和按钮意义可通过颜色、图标、文字三种信号同时识别 |
| 战报/存档/设置和模态面板 | 顶部保留窄工具按钮，模态层使用统一钢灰底、黄铜焦点线和纸张内容牌 | 顶层工具不会与战斗命令混淆，Android 触摸目标仍沿用现有安全尺寸 |

## 视觉规范

- **材质层**：战场外框、顶部栏、右侧检查器和底部命令栏使用 `ui_steel_panel`；命令使用 `ui_order_card`；任务牌和历史说明使用 `ui_paper_panel`；城市/选项标签使用 `ui_city_label_plate`；焦点和关键指标使用 `ui_brass_trim` 的黄铜边缘。
- **颜色层**：钢灰/蓝黑承载系统信息，暖黄铜表示可操作焦点和回合重点，纸张灰绿承载目标与历史信息。战术地图势力使用约26%的半透明区域染色，战略当前归属场使用20–23%；真实海岸、河流、铁路、地形格和行政线从覆盖层下保持可读。边界线、图例和检查器色带再提供拥有者识别，避免把 UI 颜色误认为真实历史县界。
- **文字层**：主标题使用地图字体；资源、回合、阶段使用小号 kicker + 大号数值；说明文字使用低对比灰绿；禁用命令降低亮度但不隐藏原因，提示仍通过 `tooltip_text` 保留。
- **层级层**：地图是底层；任务牌、图层壳和小地图是地图内浮层；选中单位/城市检查器和底部命令是战区外壳；战斗播片、暂停和模态面板在最上层。该顺序与现有 `MapView` 的静态背景/单位/前景缓存边界一致。

## 可核验的改动

1. `app/main.gd` 增加 `ui_panel`、`ui_rule`、`ui_kicker`、`ui_stat`，集中生成四类材质和资源芯片，避免每个页面手工使用不同的 `StyleBoxFlat`。
2. 战场构建改为顶部 `ui_hud_plate`、纸张目标牌、钢灰图层壳、地图右侧的钢灰编队/城市检查器和钢灰底部命令区；`layout_battle_hud()` 为目标牌和右侧检查器设置受信息密度约束的高度，窗口变窄时由检查器内部滚动承载内容，小地图移到左下方，规则层、地图坐标、单位选择和输入协议不变。
3. 部队检查器增加当前势力色带和“编队检查器”标题；城市检查器增加当前控制色带和“城市检查器”标题；攻击预览继续使用纸张色目标牌，伤害/反击数字没有改写。
4. 命令卡的图标来自 Sub2 `assets/icon` 原图；燃油、白银、结束回合、外交、暂停和 HUD/模态边框素材均通过同一路线独立生成并登记在 `assets/manifest.json`，未裁切、拼接、补绘或生成运行时合成位图。新增 UI 视觉只是控件材质、布局和图标引用。

## 与 EW6 的边界

当前版本已经对齐“战场信息架构 + 钢灰/黄铜/纸张视觉语言 + 图标化命令反馈”，但不声称与商业作品的全部页面、所有图标动作或源码结构相同。EW6 的原始 UI 资源、字体和具体交互实现没有复制；本项目仍需后续逐页补齐征服选择、生产/外交/科技面板的统一卡片密度，并进行 1280×720、2400×1080、Android 安全区的人工观感验收。
