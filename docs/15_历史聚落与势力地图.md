# 历史聚落与势力地图 · 0.2.7

本次在五倍格网基础上，增加67个有历史名称与位置依据的地方节点：56处县城、9处村落、2处省城。中国东部全图收录全部67处，京奉32处、京津23处、宁浦1处；汉口江段范围内没有新增未经核实的节点。原有城市继续作为征募、建设、补给与占领据点；新增地方节点用于地图阅读和历史详情，不冒充67座新增可征募城市。

## 年代与位置

| 类别 | 实际例子 | 核对依据 |
| --- | --- | --- |
| 县城 | 抚宁、昌黎、卢龙、迁安、遵化、玉田、宝坻、蓟县、正定、平遥、潍县、蕲水等 | 1914年《政府公报》省道县区域表，地方政府公开沿革 |
| 村落 | 北营子、板厂峪、董家口、城子峪、爨底下、灵水、三家店、琉璃渠、岔道 | 省市文物与自然资源部门资料、长城村落田野调查 |
| 省城 | 安徽安庆、河南开封 | 安庆市官方概况、开封党史地方史志研究室 |
| 既有节点分级 | 北京首都；天津、南京等省城；唐山、石家庄等集镇；山海关为临榆县治与关隘 | 当时建置与省署迁移资料；军用城池等级单独显示 |

历史行政信息来自[1914年各省所属道区域表](https://zh.wikisource.org/zh-hans/各省所屬道區域表)、[1914年京兆地方区域表](https://zh.wikisource.org/wiki/京兆地方區域表)。宝坻、蓟县归入京兆地方；岔道所在延庆在本期归直隶，不提前使用1928年后的察哈尔省。使用蕲水、潍县等当时名称。天津省城标记限1920—1924；未核实1925迁移的确切日期，不编造某一天的省署迁移事件。

安庆、开封采用这一时期的省城身份；合肥、郑州采用县城身份。高要匹配肇庆旧城区居民点，江都匹配扬州旧城区居民点，避免使用现代迁移后的县级行政中心。洛阳、芜湖、襄阳、咸宁的现代城市中心无法可靠表示本期县治，暂列待核实而不擅自补坐标。

地理位置采用GeoNames中国居民点资料中的同名P类节点，保留ID、WGS84经纬度和资料SHA。它只提供同名聚落的大致位置，不决定民初行政等级。爨底下、琉璃渠、岔道使用官方地方说明对应的粗定位，明确记录1500米精度；其他点按1000米大致定位记录。不是旧县署的测绘坐标。标志通过同一地图投影绘制，地名避让只移动标签并附引线，不移动聚落本身。

## 势力色块

底色使用ENP-China对应年代的真实省级矢量轮廓，裁切到Natural Earth陆地和战区范围；省内按据点影响分区。颜色由当前战局城市所属势力驱动，占城后更新，同步显示在小地图。不同势力使用蓝、赭红、土黄、绿等克制的颜色，保留纸面纹理、高程、河道和铁路的可读性。

图例明确写“当前战局势力 · 城池控制区”。这是当前游戏控制层，与历史省界及地方行政信息分开；不宣称这些分区是档案测定的军阀实际边界或县界。没有把今天的省份边界套入本期，也没有自行补画缺失的京兆边界。当前关卡没有启用的地方据点保持参考身份，不任意补造归属。

## 显示与操作

新增4张Sub2生成原始素材，分别表示村落、集镇、县城、省城。采用自然绿色/蓝绿色地表、立体微缩景物和钢灰UI，与欧陆战争6方向一致；素材是聚落类型符号，不声称复原每处城墙和街道的精确平面。原PNG、提示词、源SHA与工程副本保留，未拼接、裁切、翻转、补绘或手工缩放源图。运行时由Godot缩放显示。靠海处若整个图标轮廓无法落在陆地内，使用位置标志，避免把建筑画进海里。

远景优先显示首都、省城、战略城市；县城、集镇、村落随放大逐级出现，选中的地方保持可见。标签避开部队、既有城市标签、势力图例、任务卡、图层按钮与小地图；按控件实际尺寸避让，150%字号时按钮向地图内扩展。右侧“势力”“地名”可切换图层，“查地名”进入地方查询。鼠标与触屏点选均能打开名称、等级、隶属和当前战局邻近据点；地图拖动继续平移，选中部队时保留蜂窝命令输入。

地名按屏幕字号测量和绘制，避免五倍地图缩小时生成过大的字形纹理。标签优先级、可见部队避让点和固定字号文本宽度缓存；选择、地图或战局变化会更新缓存，平移仍按当前视口计算边界与冲突。性能测试的战斗阶段统计当前实际战局，不再交替查询旧快照；实际编队数量逐阶段记录。

## 复现与证据

- `tools/compile_settlements.py`读取官方点库和年代省级资料，输出`presentation/data/settlements_v023.json`及`reports/settlement_compilation.json`。
- `tools/validate_settlements.py`独立检查原居民点、投影、当时名称、省城身份、原始地图字节及全部三年代/五图色块的完整覆盖和边界，202项通过。
- `tests/historical_places_test.gd`检查原生鼠标/触屏、拖动、选中部队、图层关闭、缩放级别、占领颜色缓存更新、切换地图及规则状态不变，18项通过。
- 导出的EXE保留全图、村落、县城、集镇、省城和X30尺寸查询截图；APK逐字节校验同一聚落JSON、素材清单和导入纹理。手机物理验收单独记录。
- 点库与许可见`design/geodata/settlements/`及工程`assets/legal/GEONAMES-NOTICE.txt`。素材原图与提示词位于`output/imagegen/warlord/settlements_v023/`，随工程交付。
